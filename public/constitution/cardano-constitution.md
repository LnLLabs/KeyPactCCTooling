# Cardano Constitution (fallback)

If the app cannot fetch the latest constitution from IntersectMBO GitHub,
paste the contents of
`cardano-constitution-2.txt.md` from
https://github.com/IntersectMBO/cardano-constitution
into this file and restart the Vite dev server.

Primary remote source (override with `VITE_CONSTITUTION_URL`):
https://raw.githubusercontent.com/IntersectMBO/cardano-constitution/main/cardano-constitution-2/cardano-constitution-2.txt.md
